# OBS Overlay Maker

OBS Studio向けのブラウザソース用オーバーレイを、ブラウザ上で組み立てるエディタです。

## MVP

- 1920×1080キャンバス
- パネル追加
- パネルのドラッグ移動
- パネルの枠色・背景色・透明度・枠線・四隅の斜め加工の編集
- パネルの削除
- 画像生成した20種類のパネル枠と色相・彩度・明るさ調整
- 文字の追加・ドラッグ移動
- 文字内容・フォント・サイズ・色・透明度・太字・配置の編集
- 星・ハート・ひし形・円・三角形の追加と編集
- ゲーム画面のスクリーンショットを参照用の最背面レイヤーとして表示
- 参照画像の透明度調整と取り外し
- パネル追加・移動、参照画像操作のUndo／Redo
- 編集状態（参照画像を含む）のブラウザ保存と復元
- OBSブラウザソース用HTMLの書き出し
- Node.js標準テストランナーによる自動テスト
- 右側プレビューを画面内に固定し、左側ツールバーのみスクロール
- 将来的に時計を追加予定

参照画像はレイアウト確認専用で、オーバーレイの構成要素には含まれません。
そのため、OBS用HTMLにも書き出されません。大きな参照画像はブラウザの保存容量を超える場合があります。
参照画像は読み込み時に最大1920×1080へ縮小し、WebP形式へ軽量化します。入力できる画像は50MBまでです。

## 起動

`index.html` をブラウザで開いてください。

ローカルファイルとして開いた場合も、画像枠をOBS用HTMLへ埋め込む際は公開サイト上の同一素材を予備取得します。そのため画像枠付きHTMLの書き出しにはインターネット接続が必要です。
